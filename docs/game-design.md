# 游戏设计草案

## 1. 玩法

- **类型**：横版动作冒险
- **核心循环**：探索 → 战斗 → 解谜 → 剧情选择 → 进入下一节点
- **操作**（暂定）：移动、跳跃、攻击、技能、交互、视角切换

## 2. 视角切换

| 视角 | 渲染 | 镜头 | 适用场景 |
| --- | --- | --- | --- |
| 2D | 2D 精灵 + 视差层 | 固定横版跟随 | 复古、性能优先 |
| 2.5D | 2D 精灵 + 3D 场景 | 带轻微透视的横版跟随 | 增强纵深感 |
| 3D | 全 3D 模型 | 自由旋转 / 轨道 | 探索、Boss 战 |

> 三种视角共享同一套关卡 / 角色 / 状态数据，切换只替换渲染管线。

## 3. 关卡结构

```
章节
 └─ 场景（可对应绘梦一个场景图）
     └─ 节点（可对应绘梦一个分镜镜头）
         ├─ 对话 / 过场
         ├─ 战斗
         └─ 解谜
```

## 4. 与绘梦的资产映射

| 绘梦资产 | 次元宇宙用途 |
| --- | --- |
| 角色设定 | 可操控角色 / NPC / Boss |
| 场景描述 + 场景图 | 关卡背景 / 环境贴图 |
| 分镜脚本 | 关卡节点顺序 / 过场演出 |
| 资产库 | 通用美术资源（道具 / UI / 特效） |
